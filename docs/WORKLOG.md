# XBASE 작업 기록

## 2026-08-16 — 중간 화면 폭 헤더 메뉴 복원

- 일반 메뉴가 사라지는 반응형 기준을 980px에서 760px로 조정
- 761~980px에서는 CTA만 숨기고 About·Impact·Work 등 전체 메뉴 유지
- 760px 이하에서만 햄버거 메뉴로 전환

## 2026-08-16 — 헤더 워드마크 간격 조정

- 헤더 심볼과 `XBASE.` 사이 간격을 10px에서 3px로 축소
- SVG 내부 여백을 고려해 심볼과 텍스트가 하나의 로고로 보이도록 결합감 개선

## 2026-08-16 — 헤더 로고 원형 프레임 제거

- 헤더 로고의 원형 마스크와 그림자를 제거해 SVG 심볼만 표시
- 헤더 안의 로고 크기와 중앙 정렬은 유지

## 2026-08-16 — 수정 로고 원본 적용과 헤더 배치 교정

- 새로 제공된 `Frame 1 (1).svg` 원본으로 로고 교체
- 임의로 적용했던 SVG 표시 영역 크롭 제거
- 헤더 로고를 데스크톱 32px, 모바일 30px 원형 프레임 중앙에 고정

## 2026-08-16 — XBASE 로고 교체

- 제공된 `Frame 1.svg`를 XBASE 공식 벡터 로고로 적용
- 헤더, 히어로 구체, Beyond Marketing 섹션, 푸터의 로고 교체
- 파비콘, Apple 아이콘, 구조화 데이터의 로고 경로를 SVG로 통일
- 작은 아이콘에서도 심볼이 선명하도록 SVG 바깥 표시 여백 최적화

## 2026-08-16 — 히어로 문구 시작선 광학 정렬

- 영문 상단 문구와 한글 메인 제목의 글리프 시작선 차이 보정
- 데스크톱 6px, 모바일 3px의 왼쪽 광학 여백 적용

## 2026-08-16 — 히어로 상단 문구 크기 조정

- 히어로 상단 정체성 문구를 데스크톱 12px에서 14px로 확대
- 모바일 문구를 9px에서 11px로 확대해 가독성 보완

## 2026-08-16 — Pretendard 타이포그래피 체계 정리

- 홈페이지와 세부 페이지의 글꼴을 Pretendard로 통일
- 글자 굵기를 Light 300, Regular 400, Medium 500, SemiBold 600 네 단계로 제한
- 본문, 보조 설명, 라벨, 제목과 버튼의 역할에 맞춰 굵기 위계 재설계
- 데스크톱과 모바일의 히어로, 섹션 제목, 본문, 카드 제목 크기와 행간 조정
- 실제 렌더링에서 Pretendard 단일 글꼴과 네 가지 굵기만 사용되는지 확인

## 2026-08-16 — 새 로컬 작업 환경 구성

- GitHub 원본 저장소를 새 작업 공간에 연결
- 프로젝트 의존성을 설치하고 `http://localhost:3000/` 개발 서버 실행 확인
- 새 환경에서도 필수 네이티브 구성요소가 설치되도록 pnpm 빌드 승인 설정 추가
