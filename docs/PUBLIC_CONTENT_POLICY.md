# XBASE 공개 콘텐츠 안전 기준

XBASE 홈페이지는 불특정 다수가 볼 수 있다. 개인적으로 전달하는 이력서·PDF 포트폴리오와 공개 기준을 분리한다.

## 공개 가능

- 익명화된 업종과 지역 수준의 경력
- 수행한 역할의 범위
- 문제 해결 방식과 공개 가능한 과정
- 본인이 제작한 공개 가능한 이미지
- 공개 허가를 받은 프로젝트 결과
- 일반적인 기술·도구·협업 방식

## 사전 확인 후 공개

- 정확한 성과 수치와 예산
- 회사 실명과 로고
- 내부 프로젝트명
- 실제 화면 캡처와 보고서
- 동료·파트너·원장의 이름이나 발언
- 의료광고 심의 문서

## 공개 금지

- 환자·고객 개인정보
- 상담 DB와 연락처
- 광고계정 ID, 비밀번호, 토큰
- 내부 URL과 관리자 화면
- 비밀유지 대상 자료
- 사실과 다른 직접 운영·리딩·성과 주장

## 역할 표현 기준

사실:

- 퍼포먼스 마케터와 협업
- 광고 유입 이후 상담·예약·내원 퍼널 분석
- 콘텐츠, 홈페이지, 고객 경험, 운영 개선
- 그로스 관점에서 우선순위와 과제 조정

사실이 아니므로 금지:

- 네이버·구글·메타 직접 세팅
- 광고 입찰·타기팅·예산 직접 집행
- 퍼포먼스 광고계정 총괄

## 공개와 비공개 포트폴리오 연결

공개 홈페이지는 호기심을 만드는 역할을 한다. 상세 증빙은 `PRIVATE CASE`, `PRIVATE PORTFOLIO` 문의를 통해 별도 제공한다. 별도 제공 전에도 회사 정책과 개인정보 여부를 다시 확인한다.
